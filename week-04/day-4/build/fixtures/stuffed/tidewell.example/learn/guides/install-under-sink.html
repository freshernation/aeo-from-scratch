How to install an under-sink filter

Updated 2025-09-03

Install under-sink filter install under-sink water filter installation under-sink filter install guide how to install under-sink filter installing an under-sink water filter tools time.

Steps

  1. Turn off the cold water supply under the sink.
  2. Fit the feed adapter between the cold supply valve and the tap hose.
  3. Mount the filter head on the cabinet wall with two screws.
  4. Drill a 12 mm hole in the sink or worktop for the filter tap.
  5. Connect the tubing, turn the water on and check for drips.
  6. Run the filter for five minutes before drinking.
