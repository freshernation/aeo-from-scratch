# Week 6 — Off-site: authority, consistency, freshness (Project 2)

> **Destination**
> You can find everything the rest of the web says about a company that differs from
> what the company says, say which of it an engine is quoting, detect hidden text and
> cloaking, and attribute every lost prompt to one step. Builders ship the audit tool as
> one command; Strategists ship the audit, with a fix order a board could act on.

Tidewell has now fixed everything it controls: access, content, markup. This week is
everything it does not: a review with a two-year-old price that the panel quotes first,
a forum post with an old cartridge rating, a directory in the wrong city, and two
competitors using tactics that work on an engine that does not check.
