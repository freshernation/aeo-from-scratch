# Bot IP ranges, invented

Same JSON format as https://openai.com/gptbot.json and
https://www.perplexity.com/perplexitybot.json (checked 2026-10-30), with addresses from
the documentation ranges (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24) so they can
never match a real visitor. Download the vendors' real files for your own logs.
