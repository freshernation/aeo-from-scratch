# Shaped like live answers, not live answers

Each file holds one answer per course prompt in that vendor's documented response
shape (read on 2026-10-30). The content is invented: the citations come from the
course's own engines on web2, decorated the way real URLs often arrive (tracking
parameters, text fragments, trailing slashes). They exist so parsers can be tested
offline. Nothing here says what ChatGPT, Claude or Perplexity actually cite.
Run `aeolab/live.py` with your own keys for that.
